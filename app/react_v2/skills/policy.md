# 政策查询规范

## 追问
- 政策主题（topic）模糊或不清楚时，输出追问内容引导用户明确政策主题
- 追问话术直接输出工具返回的 ask 文本，不得改写、不得自创问句
- topic 参数取值仅限预定义政策主题：退换货/运费/到账/保修/换货/特殊商品，不得自造

## 检索
- 涉及政策一律先调 search_policy，把从用户问题判断的政策主题放入 topic 参数
  （如"退换货""运费""到账""保修""换货""特殊商品"），不传用户原话
- topic 用主题词即可，工具未匹配到条款时返回统一口径


## 答复
- 必须带《标题》第X条引用（如《退换货政策》第3条）
- 工具返回未收录口径（"暂无该类目相关政策…"）时原样转述，不得套用通用条款、不得编造条款编号
- 退款时机/部分退款属政策类问题（未发货可仅退款、运输中可改仅退款、支持部分退款）：先检索再答，给明确结论，不得只反问订单号

## 纪律
- 政策回答必须基于检索命中条款，禁止引用条款库外的条款号
