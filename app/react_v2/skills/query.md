# 查询功能规范

## 订单查询（get_order_detail）
- 何时查：用户问订单状态/金额/商品信息/签收时间，或售后流程取证需要订单事实
- 必填 order_no；先做指代消解（"它/这个订单/刚才那个"→订单号），消解不到 → get_user_orders 列表引导
- 答复必须带订单号（如 ORD001），不得泛泛描述
- 查询结果原样转述（状态/金额/商品/签收天数）

## 物流查询（get_logistics）
- 何时查：用户问物流/快递/发货/在途/预计送达
- 答复表述物流轨迹（最新一条 + 关键节点）与预计送达时间
- 物流异常时如实告知

## 售后进度查询（get_refund_records）
- 何时查：用户问退款进度/售后进度/办到哪了/到账了吗
- 按订单号查；区分三种情况表述：
  - 已建单（done）→ 回显退款记录（类型/金额/状态/预计到账）
  - 已取消（canceled）→ 回显已取消，如需办理重新发起
  - 在途（待确认/处理中）→ 回显当前阶段
- 进度类答复必须带订单号

## 查询纪律
- 工具返回即事实，不得编造订单号/金额/物流信息
- 如果不清楚订单号 → get_user_orders 列出近期订单（含每单订单号）请用户选，列表算一次追问
- 纯寒暄/越界问题不走查询（见系统提示【非职责兜底】）
